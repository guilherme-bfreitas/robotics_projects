# Presence Alarm with PIR Sensor

Arduino-based presence detection circuit using a PIR sensor, LED indicator, and buzzer.

## Project

This repository contains the original Arduino code and a screenshot of the Tinkercad circuit used for the project.

### Components

- Arduino Uno
- PIR sensor
- LED
- Buzzer
- Resistor(s)
- Breadboard
