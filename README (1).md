# Dual Temperature Alert System

Arduino circuit that reads two temperature sensors and activates visual and audible alerts when a temperature threshold is exceeded.

## Project

This repository contains the original Arduino code and a screenshot of the Tinkercad circuit used for the project.

### Components

- Arduino Uno
- 2 temperature sensors
- Red LED
- Green LED
- Buzzer
- Resistors
- Breadboard
