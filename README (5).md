# Robotics & Arduino Projects

A collection of individual Arduino/Tinkercad projects.

Each project is kept in its own directory so it can be uploaded as a separate GitHub repository.

## Projects

| Project | Main concepts |
|---|---|
| `presence-alarm-pir` | PIR presence detection, LED, buzzer |
| `temperature-alert-system` | Temperature sensors, threshold alert, LEDs, buzzer |
| `proximity-sensor-between-cars` | Ultrasonic distance measurement, LEDs, buzzer |
| `presence-activated-light` | PIR, LDR, DIP switches, lamp control |

## Important

The Arduino source files in these repositories are the supplied original code and have not been modified.
