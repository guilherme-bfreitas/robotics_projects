# Projetos de Robótica e Arduino

Uma coleção de projetos individuais desenvolvidos com Arduino e Tinkercad.

Cada projeto é mantido em seu próprio diretório para que possa ser enviado como um repositório separado no GitHub.

## Projetos

| Projeto | Principais conceitos |
|---|---|
| `presence-alarm-pir` | Detecção de presença com sensor PIR, LED e buzzer |
| `temperature-alert-system` | Sensores de temperatura, alerta por limite, LEDs e buzzer |
| `proximity-sensor-between-cars` | Medição de distância por ultrassom, LEDs e buzzer |
| `presence-activated-light` | Sensor PIR, LDR, chaves DIP e controle de lâmpada |

## Importante

Os arquivos de código-fonte Arduino presentes nesses repositórios são os códigos originais fornecidos e não foram modificados.
