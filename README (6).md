# Presence-Activated Light

Presence-based lighting simulation using a PIR sensor, LDR, DIP switches, and an output lamp.

## Project

This repository contains the original Arduino code and a screenshot of the Tinkercad circuit used for the project.

### Components

- Arduino Uno
- PIR sensor
- LDR/photoresistor
- 6-position DIP switch
- Lamp
- Resistor(s)
- Breadboard
